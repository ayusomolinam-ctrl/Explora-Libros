
# Explora Libros

Aplicación web desarrollada como proyecto académico para la materia de Desarrollo de Aplicaciones Web.

## Descripción

Explora Libros es una aplicación web que permitirá buscar libros por título o autor y consultar información como su portada, autor y año de publicación.

El proyecto utilizará HTML, CSS y JavaScript, además de la API pública de Open Library para obtener información de los libros.
